# Учебный проект: Магазин-прокат настольных игр

## Техническое задание
Система предназначена для автоматизации работы гибридной торговой точки, совмещающей функции магазина и сервиса краткосрочной аренды настольных игр. 

**Основные функции системы:**
* **Регистрация продаж:** оформление стандартных покупок настольных игр клиентами.
* **Оформление аренды:** выдача коробок с играми на дом под залог с фиксацией сроков возврата.
* **Учет поступлений:** регистрация новых партий товаров и коробок от издательств и поставщиков.
* **Контроль просрочки:** автоматический расчет штрафного чека при нарушении сроков возврата игры.
* **Каталогизация:** распределение игр по категориям, возрастным ограничениям и издательствам.

## Требования к базе данных
База данных должна обеспечивать хранение, целостность и обработку следующей информации:
1. **Клиенты:** персональные и контактные данные, паспортные данные для договора аренды.
2. **Ассортимент:** каталог настольных игр с характеристиками (жанр, издатель, возраст).
3. **Наличие на складе:** учет конкретных экземпляров коробок и их текущего статуса (в наличии, продано, в прокате).
4. **Заказы:** история покупок клиентов.
5. **Прокат:** данные о выданных коробках, датах выдачи, планируемого и фактического возврата.
6. **Поставщики:** информация о компаниях-контрагентах.
7. **Финансовые операции:** учет продаж, внесенных залогов и штрафных выплат.

## Технологический стек
* **Язык программирования:** C# (.NET Core / .NET Framework)
* **Архитектура:** Клиент-серверное приложение (Консольный сервер + Графический UI-клиент)
* **Сетевой протокол:** TCP / HTTP Web API
* **СУБД:** MS SQL Server (LocalDB / Service-based Database)
* **ORM:** Entity Framework Core (Подход Code First) + Прямые SQL-запросы
* **Тестирование:** xUnit (Модульные тесты)
* **Паттерн проектирования:** Стратегия (Strategy) / Состояние (State)
